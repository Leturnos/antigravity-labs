# ⚡ Aether Collab Board

O **Aether Collab Board** é um canvas infinito para diagramação de arquitetura de software e quadros interativos em tempo real.

## 🌟 Destaques

- **Sincronização via WebSockets**: Integração nativa com o backend FastAPI e gerenciamento de presenças/cursores por sala.
- **Renderização Nativa Mermaid.js**: Compilação de código Mermaid.js em SVG vetorial (Microserviços, Fluxos de Autenticação, Diagramas C4 e Schemas de Banco de Dados ERD).
- **Notas Adesivas (Sticky Notes)**: Cartões editáveis em tempo real com paleta de cores estilo Aether.
- **Conectores SVG Inteligentes**: Linhas ortogonais e curvas dinâmicas ancoradas automaticamente aos nós.
- **Modo Apresentação Interativo**: Demarcação de quadros/slides com transições de câmera suaves e feixe de Laser Pointer sincronizado.

## 🚀 Como Executar

Inicie o servidor unificado na raiz do repositório:

```bash
python server.py
```

Em seguida, acesse no navegador: `http://localhost:8000/tools/aether_collab_board/index.html`.
